# Privacy Policy

Effective date: May 7, 2026

Airbnb Host Rate Exporter is a Chrome extension that helps Airbnb hosts export visible nightly prices from their Airbnb host calendar to a CSV file.

## Data The Extension Uses

When you click **Scrape rates**, the extension reads information visible on the Airbnb host calendar page in your browser, including:

- Calendar dates
- Visible nightly prices
- Currency symbol
- Optional markup percentage that you enter in the popup

The extension uses this information only to create a CSV file that you can download to your computer.

## Data Collection And Sharing

The extension does not collect, transmit, sell, share, or store your data on any external server.

The extension does not use analytics, advertising, tracking pixels, or remote code.

The downloaded CSV file stays on your computer unless you choose to upload or share it somewhere else.

## Permissions

The extension requests access to Airbnb pages so it can read the host calendar that you open in Chrome.

The extension requests the downloads permission so it can save the CSV file.

The extension requests active tab access so it can verify and work with the Airbnb tab where you clicked the extension.
